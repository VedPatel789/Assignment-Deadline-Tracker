#  Assignment Deadline Tracker (Java Swing)

A simple desktop-based Assignment Management System built using Java Swing.

---

##  Features
- Add assignments
- View all assignments
- Mark assignments as completed
- Delete assignments
- GUI-based interface

---

##  Tech Stack
- Java
- Swing (GUI)
- OOP Concepts
